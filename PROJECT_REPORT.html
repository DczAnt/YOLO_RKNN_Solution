💡 关键技术点

1. YOLOv8输出解析

输出格式：[1, C, 8400] C=7（单类别）：(x, y, w, h, obj_conf, cls_conf, final_conf) C=84（多类别）：(x, y, w, h, conf1, conf2, ..., conf80) 解析要点： - 第6行是最终置信度（已sigmoid） - 前4行是边界框（中心点格式） - 需要NMS去重（IoU阈值0.45） - 坐标映射回原图尺寸

2. RKNN输入格式

要求：4维张量 [B, H, W, C] 格式：BHWC（Batch, Height, Width, Channel） 数据类型：uint8 (0-255) 错误示例： img_np = np.array(img) # [640, 640, 3] ❌ 正确示例： img_input = np.expand_dims(img_np, 0) # [1, 640, 640, 3] ✅ outputs = rknn.inference(inputs=[img_input])

3. WSL集成

  • Windows路径映射：E:\ → /mnt/e/
  • UTF-16编码处理
  • 虚拟环境激活
  • Python脚本执行

🔧 问题修复

问题1：ONNX验证无法检测目标

现象：检测数量为0

原因：使用 obj_conf * cls_conf 计算分数（全为0）

解决：使用第6行作为最终置信度，添加NMS去重

结果：✅ 检测到3个目标，置信度正确

问题2：RKNN验证输入维度错误

现象：The input[0] need 4dims input, but 3dims input buffer feed

原因：只提供了3维输入 [H, W, C]

解决：添加batch维度 np.expand_dims(img_np, 0)

结果：✅ RKNN推理成功

问题3：图片加载失败

现象：ONNX验证结果图片404

原因：URL路径格式不匹配API路由

解决：添加简化路径API /api/results/{task_id}/{filename}

结果：✅ 图片正常显示

问题4：JSON解析错误

现象：ANSI颜色代码导致解析失败

解决：使用正则表达式移除ANSI代码

结果：✅ JSON解析成功
